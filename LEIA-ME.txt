ONDE EDITAR (tudo em app.py, bloco "Histórico profissional (E-E-A-T)")
- TIMELINE       : períodos e textos da trajetória (CONFIRME as datas antes de publicar).
- FOTOS          : fotos da página /sobre/ (alt já escrito).
- CERTIFICACOES  : certificações, períodos e imagens.
- CASOS          : projetos reais com ano. Está VAZIO de propósito: só preencha com o que aconteceu de fato.
- SAME_AS        : URLs reais de LinkedIn / Perfil da Empresa no Google (entram no schema).

COMO ADICIONAR AS FOTOS E CERTIFICADOS (sem mexer em código)
Copie os arquivos (.webp ou .jpg, até ~200 KB cada, ideal 1200 px de largura) para:
  static/img/historia/rack-1998.webp
  static/img/historia/cracha-sisnema.webp
  static/img/historia/instrutor.webp
  static/img/certificados/mcse-1995.webp
  static/img/certificados/novell-cne.webp
  static/img/certificados/citrix-cca.webp
  static/img/certificados/comptia.webp
Cada foto só aparece no site se o arquivo existir (nunca gera imagem quebrada).
Para mais fotos, acrescente uma linha em FOTOS ou CERTIFICACOES no app.py.
ATENÇÃO: antes de publicar certificados, cubra número de registro/ID e dados pessoais.

COMO PUBLICAR (GitHub -> Azure)
1. Descompacte este ZIP (a pasta .git vem junto, com o histórico).
2. No terminal, dentro da pasta sisneo-web:
     git status
     git add -A
     git commit -m "E-E-A-T: paginas /sobre e /certificacoes, schema Person, correcoes SEO"
     git push origin main
3. O GitHub Actions (main_sisneoweb.yml) faz o deploy no Azure App Service sozinho.
   Acompanhe em GitHub > Actions.
4. Testes depois do deploy:
     https://sisneo.com.br/sobre/
     https://sisneo.com.br/certificacoes/
     https://sisneo.com.br/sitemap.xml   (deve listar 10 URLs)
5. Teste o schema em: https://search.google.com/test/rich-results (cole a URL /sobre/)
6. Search Console: "Inspeção de URL" em /sobre/ e /certificacoes/ > "Solicitar indexação",
   e reenvie o sitemap.xml.

TESTE LOCAL (opcional)
  pip install -r requirements.txt
  python app.py        (abre em http://localhost:8000)
